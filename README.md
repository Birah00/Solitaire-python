# Solitaire-python
Reproduction du jeu Solitaire de Windows en Python, réalisée en binôme dans le cadre de la L3 MIAGE à l'Université Toulouse Capitole (2026).

## Fonctionnalités
- Toutes les règles du Solitaire de Windows : mélange du paquet, déplacements autorisés, détection automatique de la victoire
- Plusieurs niveaux de difficulté, avec un nombre d'annulations de coups qui dépend du niveau
- Aide au joueur : affichage des coups possibles et du meilleur coup
- Jeu automatique : l'ordinateur peut jouer la partie seul
- Rangement automatique des cartes sur les piles finales
- Sauvegarde d'une partie pour la reprendre plus tard

## Lancer le jeu
Python 3 est nécessaire. Lancer le fichier Python principal du projet.
